## Problema 1 - Valutazione limoni

Definire una variabile `numero_limoni`.

Stampare:
- `"Abbastanza limoni"` se `numero_limoni >= 4`
- `"Pochi limoni"` altrimenti

Scheletro:
```python
numero_limoni = 3

if numero_limoni >= 4:
    pass
else:
    pass
```

## Problema 3 - Area del tappeto

Definire:
- `base`
- `altezza`

Calcolare l'area con la formula:

```python
base * altezza
```

Stampare il risultato finale.

Scheletro:
```python
base = 5
altezza = 2

area = base * altezza
print(area)
```
